Labelling crops

Each page shows the reader's crop today: the solid frame, labelled with its window (W1, W2…), with ink it cuts off boxed. The dashed frame is yours: drag it to where the window should be (a plain click doesn't move it). Its size is the paper's zoom, set with the slider above; one size for every page.

Label as many pages as you like, in any way: a verdict, tags, a comment or a moved window. Pages you leave alone count as no opinion. In the strip: ✓ good, ✗ bad, ✎ comment or tags, ⤧ window moved.
